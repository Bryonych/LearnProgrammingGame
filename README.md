The game was developed using the Unity game engine. The sprites for the city scene were created by AI Games, with the licence purchased from the Unity asset store. The sprites for the character were made using a 3d model created by Markus Art and purchased from the Unity asset store. Images of the model were captured on the four isometric angles and front on. These were modified in Gimp to create sprites for the static images and the animations.
